# Insure-landing-page

## Description
A modern, responsive landing page built to showcase my frontend development skills. The page features a clean UI and is fully responsive to different screen sizes. The layout is inspired by a design from frontendmentor.io, demonstrating my ability to create a visually appealing landing page based on a provided design.

## Technologies Used 
- Frontend: React, Styled-components, CSS, Flexbox, React-Bootstrap

## Setup Instructions
- Clone the github repository
- Navigate to the project: `cd insure-landing-page`
- Install dependencies: `npm install`
- Start the development server: `npm run dev`

## Responsive Design 
This landing page is fully responsive, with custom styles tailored for different screen sizes, ranging from 830px (small screens) to 1440px (large screens).

## Learning 
- Deepend my understanding of CSS to create a smooth interface using CSS and Flexbox
- Improved my skills in building responsive layouts and handling media queries for different components
